How I Work

My Approach

A set of principles that guide how I think about and build software.

01

Simplicity First

Complex problems deserve elegant, minimal solutions. I prioritize clarity in both code and interface design — if it can be simpler, it should be.

02

Learn by Building

Real understanding comes from real projects. I learn most effectively by experimenting, making mistakes, and shipping actual working software.

03

User-First Thinking

Technology exists to serve people. Every design and engineering decision is made with real users and their practical needs in mind.

04

Clean Code Culture

Code that is readable and maintainable is as important as code that works. I actively develop habits around clean, purposeful, well-structured code.

05

Continuous Curiosity

Technology evolves constantly. I stay genuinely curious, following the field's direction and exploring what's next — not just what's comfortable.

06

Open to Collaboration

Great software is rarely built alone. I value collaboration, constructive feedback, and the kind of learning that only happens in a team.
